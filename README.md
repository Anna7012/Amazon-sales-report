# 📊 Amazon Sales Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing Amazon sales data using Microsoft Power BI. An interactive dashboard was created to understand sales performance, product categories, customer orders, and shipping and fulfillment activities.

## 🎯 Objectives
- Analyze overall sales performance.
- Identify top-performing product categories.
- Understand sales distribution across different states.
- Analyze order status and cancelled orders.
- Examine shipping and fulfillment performance.

## 🛠️ Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis

## 📈 Dashboard Sections

### 1. Executive Overview
- Total Sales
- Total Quantity
- Total Orders
- Cancelled Orders
- Average Order Value by Status
- Total Sales by Year
- Total Sales by Category

### 2. Product Analysis
- Total Sales by Size
- Total Sales by Category
- Total Sales by State
- Product category and size comparison

### 3. Shipping & Fulfillment
- Total Sales by State
- Total Orders by Fulfillment Method
- Average Order Value by Courier Status

## 🔍 Key Insights
- Total Sales: ₹15,599.43
- Total Orders: 31
- Total Quantity: 26
- Cancelled Orders: 5
- Amazon fulfillment accounts for approximately 61.29% of orders.
- Kurta is the highest-selling product category.
- Maharashtra has the highest sales among the displayed states.

## 📂 Project Files
- `amazon sales report.pdf` – Dashboard report containing all three dashboard pages.

## 💡 Conclusion
This project demonstrates how Power BI can be used to transform sales data into meaningful visual insights. The dashboard helps understand sales trends, product performance, geographical distribution, and order fulfillment.
